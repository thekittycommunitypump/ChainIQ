FAQ

Clear answers. No hype.

What is ChainIQ?

ChainIQ is a planned browser-based Solana on-chain intelligence platform for token, wallet and transaction analysis.

What is $CIQ?

$CIQ is the planned ecosystem token associated with ChainIQ.

Is $CIQ already live?

No. The current site describes the planned configuration. The token mint should be published and independently verified only after creation.

Can the website guarantee a token is safe?

No. ChainIQ provides transparent signals and evidence to support investigation. It is not a security audit and cannot guarantee safety.
