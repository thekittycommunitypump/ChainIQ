FAQ

Clear answers.
No hype required.

Core information about the new ChainIQ direction.

What is ChainIQ?

ChainIQ is a planned on-chain intelligence platform focused on Solana token, wallet and transaction analysis, with an AI investigation layer.

What is $CIQ?

$CIQ is the ecosystem token associated with ChainIQ. The platform is designed so token utility can connect to real intelligence and developer services.

Is there a presale?

No. The current project configuration is presented as having no presale.

Can the token supply be increased?

The project configuration is intended to have no mint option / no mint authority. The final on-chain contract address should be published and independently verified before treating this as a live-chain claim.

Is ChainIQ live today?

This website is the product foundation. Live blockchain data, AI infrastructure, APIs and other features should only be labeled LIVE after their integrations are actually deployed.
