CHAINIQ WEBSITE
================

Files:
- index.html       Main ChainIQ website
- logo.svg         Self-contained ChainIQ logo

Open index.html in a modern browser.

The Token Scanner uses Solana mainnet JSON-RPC directly from the browser.
Paste a Solana SPL token MINT address (not a wallet address).

The site includes:
- ChainIQ branding
- Live Solana mint-account analysis
- Supply / decimals
- Mint and freeze authority checks
- Largest token-account display
- $CIQ information
- Roadmap
- AI / Network product sections
- Feedback form configured for mujahid.shibzada500@gmail.com

Important:
Live product features should only be labeled live after their real backend/indexer/AI services are deployed.
The token contract address is intentionally not hard-coded because the final deployed $CIQ mint address has not been supplied.
